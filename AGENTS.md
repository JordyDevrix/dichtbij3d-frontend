# Agent Instructions for dichtbij3d Frontend

## Project Context
This is a React Native / Expo application frontend.

## Commands
- **Install Dependencies:** `npm install`
- **Start Development Server:** `npm start` or `npx expo start`
- **Test:** `npm test` (if configured)

## Agent Rules
- Always install dependencies before running any scripts if `node_modules` is missing or outdated.
- Avoid modifying the `android/` directory or `.expo/` directory directly unless absolutely necessary.
- Respect the TypeScript/JavaScript configurations in place.
- Do not commit any changes without user permission.
