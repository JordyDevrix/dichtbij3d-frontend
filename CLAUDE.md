# dichtbij3d Frontend

This is the frontend repository for Dichtbij3D, built with React Native and Expo.

## Tech Stack
- React Native
- Expo
- Node.js (NPM)

## Guidelines
- Use functional React components and hooks over class components.
- Adhere to the existing code style and linting setup.
- Consider cross-platform (iOS and Android) compatibility when making UI changes.
- Ensure `package.json` and `app.json` are maintained correctly.
